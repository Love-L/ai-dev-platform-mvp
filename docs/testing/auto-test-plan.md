## 二、E2E冒烟测试 (Victauri)

### TC-S001: 应用启动验证
- **优先级：** P0
- **前置条件：** 无
- **步骤：**
  1. 启动应用
  2. 等待主窗口加载完成
  3. 验证侧边栏导航存在
  4. 验证默认显示工作台页面
- **预期结果：**
  - 窗口标题包含"ACE"
  - 侧边栏显示：工作台、项目管理、需求管理、任务看板、Agent、会话管理、Skill管理、代码提交、统计报表、Token消耗、设置

- **验收标准：** Given 应用已启动 → When 查看工作台 → Then 显示4个统计卡片和最近活动列表

### TC-S002: 导航功能验证
- **优先级：** P0
- **前置条件：** 应用已启动
- **步骤：**
  1. 点击侧边栏"项目管理"
  2. 验证页面切换
  3. 依次点击所有导航项
  4. 验证每个页面正确加载
- **预期结果：** 每个导航项点击后页面正确切换，无白屏或报错
- **验收标准：** 所有10个导航项可正常切换

### TC-S003: 状态栏监控验证
- **优先级：** P0
- **前置条件：** 应用已启动
- **步骤：**
  1. 查看底部状态栏
  2. 验证显示CPU、内存、活跃会话数
  3. 等待2秒
  4. 验证数据自动刷新
- **预期结果：**
  - 显示CPU使用率（百分比）
  - 显示应用内存（MB格式）
  - 显示活跃会话数
  - 数据每2秒自动更新
- **验收标准：** 状态栏显示应用资源使用情况，数据实时刷新
