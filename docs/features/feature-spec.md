## 二、现有功能详细描述

### F001: 工作台概览

**功能编号与名称：** F001 工作台概览
**目标用户与角色：** 单人开发者（唯一用户）
**使用场景：** 启动应用后查看项目整体状态
**前置条件：** 应用已初始化，数据库已创建
**主流程：**

1. 用户启动应用，默认显示工作台
2. 系统加载需求、任务、项目数据
3. 显示4个统计卡片（需求总数、任务总数、已完成、已阻塞）
4. 显示最近活动列表（合并需求和任务，按时间排序）
5. 显示项目列表（最多5个）
   **异常流程：** 数据加载失败显示错误提示
   **边界条件：** 无数据时显示空状态提示
   **输入与输出：** 无输入，输出统计数据和列表
   **依赖关系：** 依赖RequirementsStore、TasksStore、listProjects API
   **约束条件：** 列表最多显示8条活动、5个项目
   **状态变化：** 无
   **权限控制：** 无（单用户）
   **验收标准：**

```
Given 应用已启动
When 查看工作台
Then 显示4个统计卡片和最近活动列表
And 点击卡片可跳转到对应页面
```

### F002: 项目管理

**功能编号与名称：** F002 项目管理
**目标用户与角色：** 单人开发者
**使用场景：** 创建和管理项目
**前置条件：** 应用已初始化
**主流程：**

1. 用户点击"项目管理"进入项目列表
2. 可搜索项目（按名称、描述）
3. 点击"新建项目"打开创建弹窗
4. 填写项目名称、描述、标识（前缀）
5. 创建成功后显示在列表中
6. 点击项目进入详情页（5个Tab：概览、需求、任务、Skill配置、MCP配置）
   **异常流程：**

- 项目名称为空：按钮置灰
- 项目名称超过100字符：前端拦截
- 删除有关联数据的项目：后端拒绝
  **边界条件：**
- 项目标识最大10字符
- 项目名称最大100字符
  **输入与输出：**
- 输入：项目名称（必填）、描述、标识
- 输出：Project对象
  **依赖关系：** 依赖ProjectsStore、ProjectService
  **约束条件：** 无
  **状态变化：** 项目状态：active → paused → archived
  **权限控制：** 无
  **验收标准：**

```
Given 项目列表有3个项目
When 点击"新建项目"并填写名称
Then 创建成功，列表刷新显示新项目

Given 项目有5个关联需求
When 进入项目详情页的需求Tab
Then 显示5个需求的标题、状态、优先级
```

### F003: 需求管理

**功能编号与名称：** F003 需求管理
**目标用户与角色：** 单人开发者
**使用场景：** 创建和管理需求
**前置条件：** 应用已初始化
**主流程：**

1. 用户点击"需求管理"进入需求列表
2. 可搜索需求、按状态/类型筛选
3. 点击"新建需求"打开创建弹窗
4. 填写标题、描述、优先级、类型
5. 创建成功后自动跳转到需求详情页
6. 详情页可编辑基本信息、生成PRD文档
   **异常流程：**

- 标题为空：按钮置灰
- 标题超过200字符：前端拦截
- 非法状态流转：后端拒绝
  **边界条件：**
- 标题最大200字符
- 状态流转遵循状态机规则
  **输入与输出：**
- 输入：标题（必填）、描述、优先级、类型
- 输出：Requirement对象
  **依赖关系：** 依赖RequirementsStore、RequirementService
  **约束条件：** 状态流转规则：draft→reviewing→approved→in_development→testing→completed
  **状态变化：** 需求状态：draft → reviewing → approved → in_development → testing → completed
  **权限控制：** 无
  **验收标准：**

```
Given 需求处于"reviewing"状态
When 将状态改为"approved"
Then 允许流转，需求详情页更新状态

Given 需求处于"completed"状态
When 尝试改回"draft"
Then 拒绝操作，提示"已完成的需求不可回退"
```

**使用场景：** 查看和管理任务状态

6. 拖拽任务卡片可更改状态
7. 点击任务卡片进入详情页

- 拖拽到相同列：忽略

- 输入：标题（必填）、类型、优先级

  **约束条件：** 任务状态：pending → in_progress → completed / blocked
  **状态变化：** 任务状态通过拖拽更新
  **权限控制：** 无
  **验收标准：**

```
Given 看板有5个任务
When 拖拽任务从"待开发"到"开发中"
Then 任务状态更新，卡片移动到对应列

Given 任务处于"开发中"状态
When 点击任务卡片
Then 进入任务详情页，显示完整信息
```

### F005: Agent管理

**功能编号与名称：** F005 Agent管理
**目标用户与角色：** 单人开发者

**前置条件：** 已安装Claude Code或Codex CLI

1. 用户点击"Agent"进入Agent管理页
2. 系统自动发现本地安装的Agent

- 无

- 输入：Agent路径
- 输出：AgentSession对象
  **依赖关系：** 依赖AgentService、PtyService
  **约束条件：** 最大同时运行3个会话（设计文档）
  **状态变化：** 会话状态：created → launching → running → completed/failed
  **权限控制：** 无
  **验收标准：**

```
Given 系统已安装Claude Code
When 点击"刷新检测"
Then 显示可用的Agent列表

Given 点击"启动"按钮
When Agent启动成功
Then 显示运行中的会话，终端可交互
```
